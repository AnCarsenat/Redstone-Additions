## Crafting Items

| Namespace ID | Display name | Recipe |
| ------------ | ------------ | ------ |
| ra_infinite:generator_casing | Generator Casing | Ring of 8 `minecraft:copper_grate` around 1 `minecraft:netherite_ingot` |
| ra_infinite:mineral_core | Mineral Core | Sacrifice `minecraft:stone` on an enchanting table (1%) |
| ra_infinite:nether_core | Nether Core | Sacrifice `minecraft:netherrack` on an enchanting table (1%) |
| ra_infinite:poppy_core | Poppy Core | Sacrifice `minecraft:poppy` on an enchanting table (1%) |
| ra_interactive:enchanted_coal | Enchanted Coal | Sacrifice `minecraft:coal` on an enchanting table (1%) |
| ra_interactive:enchanted_coal_block | Enchanted Coal Block | Nine Enchanted Coal |
| ra_enchanting:schematic | Schematic | Throw an enchanted book on a Book Printer (2%); not craftable |
| ra_automation:pattern | Pattern | ![Pattern recipe](images/recipes/ra_automation/pattern.png){ width="220" } |
| ra_farming:capture_net | Capture Net | ![Capture Net recipe](images/recipes/ra_farming/capture_net.png){ width="220" } |
| ra_farming:master_capture_net | Master Capture Net | Sacrifice an empty Capture Net on an enchanting table (35%) |
| ra_ender:overstar | Overstar | Sacrifice `minecraft:nether_star` on an enchanting table (10%) |
| ra_automation:recipe_pattern | Recipe Pattern | ![Recipe Pattern recipe](images/recipes/ra_automation/recipe_pattern.png){ width="220" } |

The Generator Casing and the Cores cannot be placed as blocks. A Schematic is paper carrying a book's enchantments in `custom_data` (`{ra:{schematic:1b,enchantments:{...}}}`), right-clicked into a [Book Printer](enchant-crafting.md#setting-the-schematic) to set what it prints. A Pattern is paper carrying a 3×3 grid of item ids (`{ra:{pattern:{slots:[<9 ids or "">]}}}`, see [Automation](automation.md#pattern-data)); a Recipe Pattern is the same with `recipe:1b` beside `slots`. A Capture Net is a rabbit hide wearing the cobweb model; it carries a caught mob in `custom_data` (`{ra:{capture_net:{mob:{id,type,data}}}}`, see [Farming](farming.md#capture-net)). The Master Capture Net is an empty Capture Net that survived an enchanting table; a net holding a mob is never taken. The Overstar is a test instance block wearing the nether star model (`{ra:{overstar:1b}}`), so the Anchor Tablet recipe takes no other item; it cannot be placed, and only plain nether stars become one (see [Ender Links](ender-links.md#overstar)).

| ra_jetpacks:infinite_jetpack_kit | Infinite Iron Jetpack Kit | Sacrifice an Iron Jetpack Kit on an enchanting table (1%) |
