# Redstone Additions: v6.0.3 plan

What v6.0.3 will contain, decided from the brainstorm. Anything not listed here is out of scope
for this version. Items marked **(to design)** need a short design note before work starts.

## 1. Fixes and technical work

- **Oversized network rebuilds.** A single loaded network of more than ~1500 nodes cannot finish
  a rebuild within the command limit, and since 6.0.2 it retries every 5 ticks, cutting the rest
  of the tick each time. **(to design)**: write up every way to solve it, with pros and cons
  (stop after N failed attempts and warn admins, run the rebuild as its own tick entry, split one
  network across ticks, cap the intake of new nodes, …), then pick one.
- **Ender link partner search.** Finding a vault's partner visits every receiver in the world, so
  the cost grows with the square of the number of vaults. **(to design)**: same as above, list the
  options with pros and cons (index receivers by channel with a score or tag, cache the partner,
  limit the search, …), then pick one.
- **Poured potion colour.** A poured potion can show the default blue when the pour empties the
  network, because the colour is read after the take. Read it first. Small fix.
- **Input sanitising in the core.** A core way to clean player input so it can never run or
  extend a command. With it, some settings that are admin-only today could be opened to players
  again.
- **Shared formulas as number providers.** Move formulas used in several places (solar curve,
  bridge levelling, thruster smoothing, …) into named 26.3 `number_provider` files that
  `/compute` references.
- **Item and signal network classes.** The brainstorm proposed two new kinds of network: an item
  network (pipes that pool items like tanks pool fluids, with drawers and import/export points) and
  a signal network (cables that carry the highest redstone level of their sources). **(to
  explain)** before deciding whether they are in.

## 2. Rules and UI

- **Coordinates input.** A simple way to enter relative, look-relative (`^`) and absolute
  coordinates for blocks that need a position. **(to design)**
- **Admins bypass range limits.** Range and radius maximums do not apply to admins.
- **Admin-only actions stay visible.** When a player can do something only because they are an
  admin, the menu still shows it, marked as admin-only, rather than hiding the difference.
- **Remove the Upgrade Platform.**

## 3. Existing modules

### Logic Gates
- **Counter**: counts pulses and outputs when it reaches a target, with a reset.
- **Signal Calculator**: maths on signal levels (A+B, A−B, max, min, comparisons, invert).
- **Edge Detector**: pulses on a rising edge, a falling edge, or both.
- **Sequencer**: steps through up to 15 outputs, one per pulse, with a reset input.

### Sensors
- **Block Detector**: detects a block type at a set position.
- **Light Sensor**: outputs the light level in front of it.
- **Weather Sensor**: rain, thunder, day or night.
- **Held Item Detector**: detects players carrying an item in the main hand, the offhand, either
  hand, or anywhere in the inventory.
- **Player Detector**: detects players from a list of names.

### Interactive Machines
- **Elevator**: jump to go up, sneak to go down, to the next Elevator in the column.
- **Trash Can**: destroys whatever enters it.
- **Fan**: pushes items, mobs and players along its face, up to a set range (like a Conveyor
  with a reach).

### Transport networks
- **Grid / Tank Gauge**: outputs redstone from a network's fill level.
- **Usage Meter**: sends a redstone pulse every N units consumed or produced on a network (for
  electricity or fluid bills).
- **Gas Vent**: releases a gas network's content into the area, like the Liquid Drain pours.
  Oxygen gives water breathing, toxic gases wither players; other packs' gases can hook in.
- **Air Tank and Heavy Boots**: a new chestplate filled with air from a gas network, giving
  15 minutes of underwater breathing when full. Heavy Boots stop the player floating and let them
  walk on the bottom. A charging block fills the tank.
- **Tesla Coil**: uses EU to zap every mob in a radius, with particles and sound.
- **Spout**: fills any container placed under it (bucket, bottle, …) from a fluid network.
- **Water Wheel**: EU from flowing water, with a good animation made of block displays.
- Later, in a separate **Chemistry** module (work in progress): the Electrolyser.

### Ender Links
- **Remove the destination list** added in v6.0.1 (destinations are no longer listed to pick
  from).
- **Anchor Terminal**: a block placed in the world to choose a destination.
- **Anchor Tablet**: an item that teleports to a destination from anywhere.
- Destinations come from a table, and duplicate anchor ids are refused.

### Wireless Redstone
- **Analog Emitter / Receiver**: carry a 0–15 level over a channel, not only on/off.
- **Pager**: an item that alerts its holder when its channel turns on, wherever it is in the
  inventory.

### Jetpacks
- **Fuel gauge** on screen.
- **Smoother thruster movement.**

### Multiblocks
- Open problem: it is hard for a player to tell which structure they are building. **(to
  design)**

### Enchant Crafting
- **Disenchanter**: moves an item's enchantments onto a book.
- **Book Upgrader**: raises one enchantment of a book by one level, for an exponentially rising
  price in liquid experience.
- **Book Printer**: throw an enchanted book in for a very low chance of getting its
  **schematic**; throw the schematic in to print copies of that book for a price in experience.

### Tools
- **Goggles helmet upgrade**: an expensive upgrade that gives the Goggles' view to any helmet,
  switched off with a command like the jetpack kits.

## 4. New modules

### Automation
- **Crafter Controller**: runs a vanilla crafter automatically: fires it once the crafter's
  contents match the pattern it holds.
- **Pattern** item: stores a crafting pattern, used by the Crafter Controller (and the keypad).
- **Recipe Pattern** item: stores a recipe for a more automatic crafter.
- **Item Pipe Splitter**: splits an item stream between outputs.
- **Uncrafter**: turns an item back into its ingredients, using a lot of EU.
- **Fake Player**: lets mobs spawn as if a player were nearby, so farms keep running.
- **Experience Absorber**: collects experience and sends it into a network.
- **Conveyor**: moves entities, items and players smoothly along.

### Farming
- **Sprinkler**: sprays water, or experience for 4× growth speed.
- **Breeder**: moved here from Interactive Machines.
- **Tree Farm**.
- **Capture Net**: catches a mob to carry it; can be upgraded to catch any mob.

### Displays
- **Text Screen**: shows text in a nixie-tube style, chosen by the redstone level feeding it:
  level 15 shows the name of the first item in its inventory, 14 the second, and so on. Without
  items, it shows the redstone level itself.
- **Gauge Bar**: a fill bar.
- **Item Hologram**: shows the item inside it as a floating item display.

### Railworks
- **Minecart Speed Setter**: sets the speed of a minecart passing over it when triggered.
  **(to check)**: may not be feasible.
- **Route Rail**: switches a cart's direction when the cart has a given tag.

### Audio
- **Note Sequencer**: like the Sequencer, but a 2×2 matrix so it can play chords.
- **Alarm** and **Doorbell**.
- **Jukebox Controller**.

### Security
- **Keypad**: outputs a redstone signal when the pattern entered matches the pattern it was set
  with (patterns come from the Pattern item).

Not planned for now: brewing, and everything else from the brainstorm not listed above.
