# v6.0.3 progress

Tracks every item of [the v6.0.3 plan](v6.0.3-ideas.md): its issue, branch, pull request and state
(`todo`, `in progress`, `in review`, `merged`, `needs decision`, `removed`, `disabled, not
included`). Design items (`design(...)`) first
deliver a note in `planning/design/` and wait for the maintainer's decision.

Last updated after #186 (batch 5; the previous docs update was #174). The table is built from
`gh pr list --state all --base release/6.0.3` and `gh issue list --milestone v6.0.3 --state all`.

## Where things stand

- **In review / in progress / todo:** nothing. Every feature and fix issue of the milestone has a
  merged PR into `release/6.0.3`.
- **Removed or not included:** the Tree Farm (#92, built in #176, removed by #184 for #182,
  maintainer decision 2026-11-11, no migration since it never shipped); the Fake Player (#87,
  built in #179, disabled by #186 for #181: the code stays behind `FakePlayer.ENABLED = false`,
  only its break check and mob sweep run, for dev worlds); the separate Recipe Pattern item
  (#84, folded into the Pattern by #186).
- **Dropped by the maintainer:** the Minecart Speed Setter (#97, closed) and the cart speed
  upgrade (the unbuilt part of #169). 26.3 caps every cart at 8 b/s, so neither could make a
  cart faster than vanilla; the design notes stay for reference.
- **Needs decision (left as they are):**
  - #42 oversized network rebuilds, #43 ender partner search, #47 item and signal network
    classes, #78 telling which structure is being built, #128 Sequencer redesign (design
    notes merged, see the table);
  - #99 Note Sequencer, waits on #128;
  - the Water Wheel stopping when its network is full (no issue yet).

## Decided by default (easy to change)

Choices made during the work without an explicit maintainer decision. Each is a small change
if the maintainer wants it otherwise:

- The Master Capture Net is made only by enchanting-table sacrifice of an **empty** Capture Net
  (35%; a failed roll uses the net up). The nether-star crafting recipe is gone (#185).
- The Overstar comes from nether stars thrown on an enchanting table (10%, each star used up);
  renamed stars and stars with custom data are refused (#185).
- Every Pattern fills its crafter from a vanilla container on the Crafter Controller's far
  side; without one it only compares and fires (#186).
- Gauge Bars placed before the text-display bar become transparent (#177).
- The Item Hologram's name stays upright when the item tilts (#177).
- A leashed mob is unleashed when caught by a Capture Net; one lead drops (#176).
- Placement items made before 6.0.3 keep a visible bat; new ones place an invisible one (#178).
- Uncrafters and Item Pipe Splitters still on the old blocks in dev worlds from earlier 6.0.3
  builds are refunded (#186).
